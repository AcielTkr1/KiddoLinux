# KiddoLinux

**Learn. Explore. Create.**

KiddoLinux is an educational Linux distribution designed
for children aged 6–12.

## Project Overview

- Base: Ubuntu
- Architecture: AMD64
- Desktop Environment: KDE Plasma 6
- Display Server: Wayland
- Languages: Indonesian and English

## Main Applications

- Kiddo Home
- Kiddo Learn
- Kiddo Progress
- Kiddo Parent

## Project Goals

Provide a playful, safe, accessible, and interactive
learning environment for children.
